# Sistema-Monitoreo-Fotovoltaico

## 1. Descripción del proyecto

Este repositorio contiene el software desarrollado para la propuesta de análisis y diseño de un sistema de monitoreo de una instalación fotovoltaica, mediante instrumentación de sensores y controladores.

El proyecto fue desarrollado en TIA Portal V19 y corresponde a una simulación del sistema de adquisición y monitoreo de variables.

## 2. Contenido del repositorio

- PROYECTO_FINALll.zap19: archivo de proyecto archivado de TIA Portal V19.
- README.md: documentación e instrucciones básicas de utilización.

## 3. Requisitos para su utilización

- Sistema operativo Windows.
- Siemens TIA Portal V19.
- Entorno de simulación o hardware compatible con la configuración del proyecto, según el modo de prueba utilizado.

## 4. Instalación y apertura del proyecto

1. Descargar el archivo PROYECTO_FINALll.zap19 desde este repositorio.
2. Abrir Siemens TIA Portal V19.
3. Seleccionar la opción "Retrieve" (Recuperar proyecto).
4. Buscar el archivo descargado y seleccionar una carpeta de destino.
5. Esperar a que finalice la recuperación del proyecto.
6. Abrir el proyecto recuperado para revisar su programación y configuración.

## 5. Funcionamiento de la simulación

El desarrollo permite representar el funcionamiento del sistema de monitoreo mediante señales simuladas.

Para las pruebas realizadas se utilizaron potenciómetros como elementos de generación de señales de entrada, representando las variables que en una implementación real serían obtenidas mediante sensores físicos.

Esto permite evaluar la lógica de programación y el comportamiento del sistema sin requerir la adquisición real de datos desde el panel fotovoltaico.

## 6. Alcance y limitaciones

El presente desarrollo corresponde a una propuesta validada mediante simulación.

La incorporación de sensores físicos, la adquisición de datos reales desde la instalación fotovoltaica y la implementación definitiva del sistema quedan fuera del alcance de este trabajo.
